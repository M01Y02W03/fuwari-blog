基于开源的 **Fuwari** 框架“魔改”的个人博客

# 1. 安装

``` cmd
# 安装依赖
pnpm install

# 启动项目
pnpm dev

# 新建文章
pnpm new-post <filename> 或直接在src/content/posts/目录中创建文件
```
