# 电脑编码设置

Windows 系统默认编码设置为 UTF-8（65001）的步骤。

## 操作步骤

1. 按下 `Win + R` 组合键打开运行窗口，并键入 `intl.cpl`，然后按下 Enter 键。这将打开"地区设置"窗口。

2. 在"地区设置"窗口中，将"格式"选项卡设置为你想要的地区格式，比如"英语(美国)"。

3. 点击"管理员权限"按钮，这将打开"区域设置"窗口。

4. 在"区域设置"窗口的"管理"选项卡中，点击"更改系统区域设置"按钮。

5. 在"区域设置"窗口中，选择 **"使用 Unicode UTF-8 提供全球语言支持"** 复选框，并点击"确定"。

6. 系统会提示要重新启动计算机以使更改生效。选择"是"以进行重启。
